Extension: ext:fanqie

📊 状态

⬇️ 安装与更新

对应 CLI：ppc ext call fanqie install|update --mirror/--no-mirror --mirror-host <host> [--musl] [--force]

🚀 启动

对应 CLI：ppc ext call fanqie server --host <host> --port <port> [--password <pwd> -d <data-dir>] / ppc ext call fanqie tui [-d <data-dir>]

⚙️ 配置

加载中...
对应 CLI：ppc ext call fanqie config show|get|set|path（edit 为本地编辑器操作，Web 场景用键值设置代替）

🗑️ 卸载

对应 CLI：ppc ext call fanqie uninstall [--yes]

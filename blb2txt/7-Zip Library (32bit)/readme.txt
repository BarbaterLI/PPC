The application can use the library 7z.dll (32bit). It helps to extract text and images from documents inside archives (ZIP, RAR, etc.). Copy 7z.dll to the folder where the application is located.

7z.dll is a part of 7-Zip software.

https://www.7-zip.org

7-Zip is free software with open source. You can use 7-Zip on any computer, including a computer in a commercial organization. You do not need to register or pay for 7-Zip.

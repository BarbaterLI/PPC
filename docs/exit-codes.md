# 退出码规约

| Code | 含义              | 示例                              |
|------|------------------|----------------------------------|
| 0    | 成功 / 正常工作    | 包括"无操作"场景                  |
| 1    | 业务错误          | TTS 调用失败 / 文件 IO            |
| 2    | 参数错误          | E_INPUT_NOT_FOUND / E_INPUT_EMPTY |
| 3    | 网络 / 外部依赖错误 | edge-tts 不可达                  |
| 4    | 权限错误          | 无法写输出目录                    |
| 5    | 配置错误          | E_CONFIG_MISSING / E_CONFIG_INVALID |

默认无操作场景退出码为 0;`--strict` 时退出码为 2。
